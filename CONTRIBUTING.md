# Contributing

The project has not selected a redistribution license. Open an issue before proposing third-party code or substantial contributions so the authors can agree on licensing.

For development, install `python -m pip install -e ".[dev]"` and run `python -m pytest`. Preserve failing cases, target constraints and benchmark provenance. Do not commit compiler binaries, private target profiles, credentials or machine-specific logs. Hardware-dependent experiments are separate from host-only tests.
